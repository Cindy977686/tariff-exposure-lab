# 关税暴露与企业韧性

上海对外经贸大学首届 AI 创新应用大赛 · 赛道四（数据分析与智能洞察）参赛原型。

一个交互式研究看板：选一个贸易政策冲击，看哪些行业被打得最重，再看这些行业里的  
上市公司怎么反应——投资砍了没、现金囤了没、研发停没停——最后由大模型把数字翻译成人话。

同一套数据管道同时服务两件事：比赛交付的产品，和后续那篇公司金融方向的工作论文。

### 仿真数据合规（官方明文允许）

官方原文：「采用仿真数据时，应说明生成机制与适用范围」。本项目已内置合规方案：

- **生成机制**：`core/demo_data.py` 全部参数显式（种子 42、行业冲击强度服从 Beta(2.2, 2.8)、  
  企业效应系数见代码注释），`python -c "from core import demo_data; demo_data.save_csv('data/raw')"`  
  可一键复现完全相同的数据。
- **适用范围**：应用在合成模式下于页面顶部持续展示免责声明，README 与报告写明  
  「合成数据仅用于验证管道与展示交互能力，不支撑任何经济结论」。
- **策略含义**：真实数据拿得到就用真实数据（得分上限更高）；拿不到，仿真模式也是合规提交物，  
  不需要为此放弃选题。风险等级从「数据拿不到就换题」降为「数据拿不到就降级」。

## 接真实数据

把三个 CSV 放进 `data/raw/`，字段名如下（常见中文表头会自动识别，如「年份」「证券代码」）：

**trade.csv**

| 字段           | 说明                 |
| ------------ | ------------------ |
| year         | 年份                 |
| hs_code      | HS 编码，2 位或 6 位均可   |
| partner      | 贸易伙伴，与事件匹配，默认 `US` |
| export_value | 出口额                |

**tariff.csv**

| 字段          | 说明      |
| ----------- | ------- |
| year        | 年份      |
| hs_code     | HS 编码   |
| partner     | 贸易伙伴    |
| tariff_rate | 关税税率（%） |

**firms.csv**

| 字段            | 说明                    |
| ------------- | --------------------- |
| stkcd         | 证券代码                  |
| year          | 会计年度                  |
| industry_code | 证监会行业代码，需与暴露度表的代码体系一致 |
| industry_name | 行业名称                  |
| capex_ratio   | 资本支出 / 总资产            |
| cash_ratio    | 现金及等价物 / 总资产          |
| rd_ratio      | 研发支出 / 营业收入           |
| leverage      | 资产负债率                 |
| roa           | 总资产收益率                |
| size          | 总资产对数                 |
| soe           | 是否国有（1/0）             |
| export_share  | 出口收入占比                |

数据来源建议：海关总署月度进出口（HS 章及以上）、WITS / TRAINS 关税数据、  
CSMAR 或 Wind 上市公司财务。学校图书馆一般有 CSMAR 权限，**先去确认**，这决定选题能否落地。

## 变量与识别

**行业暴露度**

```
Exposure_j = Σ_k ( 出口_kj / 出口_j ) × ( Tariff_k,事件年 − Tariff_k,基期 )
```

权重取事件前一年。用基期权重的理由：企业会因为冲击改变出口结构，若用事件当年权重，  
权重本身就被结果污染了。答辩时这条会被问，提前准备好。

**企业分组**：按行业暴露度三分位分高 / 中 / 低暴露组。

**事件研究**：`rel_year = 年份 − 事件年`，窗口 ±3 年，纵轴为相对冲击前均值的偏离，  
三条线在 t<0 期锚定在 0 附近，方便看分化。

**简化 DID**：高暴露组与低暴露组的事前事后均值差之差。只给方向，不做显著性主张。

## 已知限制（写进作品说明文档，不要藏）

1. 海关企业级微观数据公开版本止于 2016 年，覆盖不到 2018 与 2025 两次冲击，  
   因此基线用行业层面暴露度，属于数据可得性约束下的次优选择。
2. 行业暴露度对组内企业同值，标准误若不做行业聚类会偏小。
3. 事件窗口内存在其他政策叠加，结论限于相关性表述。
4. 当前映射表到 HS 章（2 位），论文阶段需细化到 HS6 加 BEC 中间品分类。
